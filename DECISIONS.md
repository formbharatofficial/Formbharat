# FormBharat — Locked Decisions

## 1. Roadmap
The official FormBharat roadmap consists of exactly 8 phases:

1. Foundation
2. User System
3. Document Vault
4. Vacancy
5. Form Intelligence
6. Assisted Form Filling
7. Application Tracker
8. Mobile UI + Security + Production

This roadmap is locked.

## 2. Current Phase
Current development phase:
Phase 2 — User System

## 3. Change-control rule
No phase, feature, architecture or major technical decision
may be changed based only on an assumption.

Any change to a locked decision requires explicit approval
from the project owner.

## 4. Development rule
Before implementing a new feature, verify:
- Which phase it belongs to
- Existing implementation
- Existing tests
- Existing project decisions

Do not duplicate or replace existing functionality without checking first.
